Funding Account Planner

Size trades to survive a prop-firm-style evaluation challenge. Pure arithmetic on the rules you enter below — not connected to any real account, and the program presets are typical, illustrative structures, not any single provider's exact terms (those vary and change). Check your own account's real rule sheet.
⚠ Pick the right "Drawdown type" — this is the single most common way traders miscalculate their real remaining budget, and getting it wrong can breach a rule while the trader still thinks they have room left.
Static — the floor is fixed below the account's STARTING balance only (e.g. a 10% max DD on a $100k account stays a $90k floor forever, no matter how high equity climbs).
Trailing — the floor RISES with the account's own peak equity. If you've grown the account, your real floor is closer to today's peak than "10% below where I started" — this tool computes that gap for you from the two P&L numbers below rather than asking you to pre-compute it yourself (the error-prone part). Check your account's real rule sheet if you're not sure which type applies — this tool has no way to know on its own.

Checking the live book…

Reading the Stage 0 gate, the re-calibrated null and the forward-test log.

The live book

Every strategy carrying an explicit stage0.status = VALIDATED tag, with the evidence chain behind it. A strategy is only as strong as its weakest link here.

What noise alone achieves

150 synthetic price paths with no edge by construction, each searched by the same 830-candidate grid the real sweeps use. Height is the best selection score the search found on pure noise. Your live strategies are the two horizontal markers — the question is whether they stand clear of the cloud.

Three block lengths are run rather than one because no single choice is correct: short blocks destroy the volatility clustering that makes a null realistic, long blocks preserve more real structure. The sensitivity is the point, not one “right” value.

How bad the fills can get

Each live strategy re-priced at multiples of assumed fill quality (0.30% round trip at 1×). The question is not what it earned at assumed costs, but where the edge crosses zero.

Forward evidence

Predictions recorded before the bar that settles them. Every other number on this page was computed over bars that already existed when the search ran; this is the only section that was not.

The scored corpus

Every candidate this project has backtested, by grade. This shape is the argument against adding more strategies: the constraint is not supply, it is that almost nothing survives an honest gate.
